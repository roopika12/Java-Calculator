# Java Calculator

A simple console-based calculator built using Java.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Repeat calculations
- Division-by-zero handling

## Technologies Used

- Java
- Scanner
- Methods
- Switch Statement
- Loops
- Git & GitHub

## How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Compile the program:

```bash
javac Calculator.java
